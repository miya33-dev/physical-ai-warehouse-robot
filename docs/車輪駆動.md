# 車輪で走る台車（2026-11-02）

## 今回の変更
台車のX/Yスライド関節と位置アクチュエータを取り除き、自由に並進・回転できる車体に、左右2つの駆動輪を取り付けました。車輪は床と接触し、摩擦とモータートルクによって車体を動かします。走行中に台車の座標や姿勢を直接書き換える処理はありません。

車輪の回転が見えるよう、タイヤに白いマーカーを付けています。前後には低摩擦の球状支持部を付けています。これは補助キャスターの簡略表現で、自在キャスターの旋回軸や転がり車輪の詳細はモデル化していません。

## 左右輪の制御
- 車輪半径 r = 0.12 m。
- 左右輪間隔 L = 0.57 m。
- 左輪角速度 = (前進速度 v - L × 旋回角速度 w / 2) / r。
- 右輪角速度 = (前進速度 v + L × 旋回角速度 w / 2) / r。

同じ速度なら前後進、反対向きならその場旋回します。車輪の目標角速度をMuJoCoの速度サーボへ渡します。駆動トルクの上限は各±12 Nmです。台車は重力下にあり、タイヤと床の摩擦を含めて計算します。アームの重力補償は維持しています。

## 経路追従
A*の経路から直線区間の中間点を省き、曲がり角を残します。曲がり角ごとに向きを合わせて前進し、目標へ近づくと減速します。停止後に向きを整えてからアームを操作します。

前進速度の上限は0.34 m/s、旋回角速度の上限は1 rad/s。目標までの距離と向きの誤差から左右輪の速度を更新します。目標へ到達しない場合はタイムアウトして停止します。

フィードバックにはMuJoCoの台車位置・姿勢を使用します。車輪エンコーダやSLAMによる自己位置推定ではありません。アームの逆運動学は台車の現在の向きを考慮し、世界座標の箱の位置を台車基準へ変換します。

## 物理検証
障害物のない場所で、0.25 m/sを2秒間指令してから停止しました。

| 条件 | 車体の移動量 | 台車全体の重心移動量 |
|---|---:|---:|
| 通常の摩擦 | 約49.5 cm | 約49.5 cm |
| タイヤと床の摩擦のみ低下 | 約9.3 cm | 約3.5 cm |
| 駆動モーターを無効化 | 約0.00008 cm | 約0.00008 cm |

低摩擦条件でもタイヤは約0.5m分回転しますが、重心の前進が大幅に減少します。支持部には摩擦が残り車体姿勢も変化するため、移動が厳密にゼロになる試験ではありません。通常条件での90度旋回は角度誤差約0.62度、位置ずれ約2.4mmでした。

少数の固定条件での結果です。滑る床、坂道、未知の障害物や任意の積載条件に対する性能は未評価です。既知地図、固定カメラ、吸着拘束の簡略化は残ります。

## 実行
LLMサーバーを起動してから実行します。

```sh
./run.sh --demo --layout-seed 0 --video --video-speed 2 --output outputs/wheel_llm_demo
./run.sh --drive-evaluate
./run.sh --layout-evaluate
./run.sh --evaluate
./run.sh --test
```

動画は outputs/wheel_llm_demo/demo.mp4、106.2秒、15fps。2倍速を映像内に明記しています。--video-speed を省略すると約1倍速となり、2件配送の動画は3分を超える場合があります。LLMの待ち時間は物理シミュレーション時間には含みません。

outputs/drive_evaluation/summary.json に走行試験、outputs/wheel_llm_demo/results.json に配送経路・左右輪の累積回転距離・接地ステップ数・停止位置の誤差を保存します。

導入前のコミットは 91bc80e（codex/randomized-layouts）。車輪駆動のブランチは codex/wheel-drive。説明資料PDFは従来の簡略台車の版なので、提出前に更新が必要です。
