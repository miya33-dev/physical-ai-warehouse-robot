# 実装と検証（2026-11-02）

## 実装したもの
MuJoCo 3.3.7で独自MJCFモデルを作成。台車のXYスライド関節、2回転＋1直動のSCARAアーム、動的な箱、作業台、障害物を含みます。位置サーボで制御し、重力・接触・吸着拘束下で箱の移動を計算します。箱を目的地に瞬間移動させる実装ではありません。

## 実行時のAI
### 言語
生成した144例で文字1-gram/2-gramの多項Naive Bayesを学習します。赤/青×出荷/保管の4クラスを推論します。モデルの判断を、許可語彙と動作語の検証と照合してから実行します。生成AI/LLMの推論ではありません。対応する言い方は限定的で、任意の日本語を理解するとは主張しません。scoreは分類器内部の相対値で、実世界の正答確率ではありません。

### 視覚
12種類の色・明るさ条件で、MuJoCoのRGB画像と教師用セグメンテーションから計18,096画素を収集します。背景・赤・青の3クラスについて、RGBと色差の5次元特徴からクラス平均・共分散を推定するGaussian分類器を学習します。推論時の入力はRGBのみです。物体IDのマスクは教師ラベル作成・評価にだけ使います。

既知の荷物置き場の範囲内で分類画素を集め、その中央値をカメラの既知パラメータと箱上面の高さから平面座標へ変換します。複数の同色箱、未知高さ、カメラ移動には未対応です。

### AI以外
A*は既知地図の経路探索、アームは解析的な逆運動学です。強化学習は行っていません。

## 統合検証
毎回初期化した同一シーンで実施。4通りの配送では指定した箱を配送できることも評価します。

| ケース | 結果 | 配置誤差 |
|---|---|---|
| 赤→出荷 | 成功 | 2.507 cm |
| 赤→保管 | 成功 | 2.508 cm |
| 青→出荷 | 成功 | 2.507 cm |
| 青→保管 | 成功 | 2.508 cm |
| 学習後に箱の色を交換し、赤を指定 | 別の箱を選択して成功 | 2.507 cm |
| 対象の赤い箱を置き場から除去 | 移動前に停止 | 対象なし |

4通りの配送と色交換の試験で、障害物との接触は0。接触判定はシミュレータの接触情報を使用し、障害物と台車・アーム・箱の1mmを超える貫入を数えています。一般的な衝突保証ではありません。

単体テストでは日英の指示、曖昧・未対応・否定指示の拒否と、膨張障害物を通らない経路を確認しました。全ての否定表現や複雑な文章に対応するわけではありません。

学習と異なる標準色で描画した1画像の画素分類精度は、背景100%、赤・青とも99.44%。合成データ・同一視点・同じ背景での限定的な検証であり、現実画像や未知環境での精度ではありません。

## デモ
赤→出荷、青→保管を連続実行。MP4、960×640、15fps、149.6秒。シミュレーション時間にほぼ対応する速度（約1倍）。後半は最初の配送先から荷物置き場へ戻るため長くなります。障害物接触0、配置誤差は各約2.5cm。

## 制約と今後
- 台車はXY位置サーボ。車輪・摩擦による駆動はモデル化していません。
- 吸着は接近を確認してから固定拘束を有効化。接触指による把持ではありません。
- 既知地図、固定カメラ、既知の高さを使用。SLAMや未知物体の6D姿勢推定はありません。
- 固定シーンの少数の決定的な試験です。ランダム配置や多数回の頑健性評価は未実施。
- 認識は対象色の画素をまとめる簡易方式であり、同色物体の個体識別や一般的な物体検出モデルではありません。
- 言語理解をLLMに置き換える場合も、構造化出力の検証を維持します。
