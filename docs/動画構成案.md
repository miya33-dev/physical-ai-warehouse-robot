# 動画構成案（約90秒）

以下は制作前の90秒構成案です。現在の実装版は outputs/demo/demo.mp4（149.6秒）に保存済み。赤→出荷、青→保管の2件の連続動作を収録しています。

- 0〜10秒: タイトル、目的、倉庫全景。
- 10〜20秒: 「赤い箱を出荷場所へ」の指示とAIの解釈結果。
- 20〜40秒: カメラ画像、認識した箱、アームでのピッキング。
- 40〜60秒: 障害物を避けて移動し、配送先へ配置。
- 60〜75秒: 別の指示で青い箱を運ぶ。
- 75〜90秒: 工夫点、実測した結果、制約。

倍速編集時は表示する。画面録画にはアカウント情報、メール、通知、認証情報を映さない。
