# 指でつかむグリッパ（2026-11-03）

把持機構は現在も有効です。ここでの認識・動画・統合評価はYOLO導入前の記録です。最新の認識については [YOLO導入](YOLO導入.md) を参照。

## 吸着からの変更
吸着の固定拘束を削除し、左右に動く2本の指を追加しました。指で箱の側面を挟み、接触と摩擦で重力を支えます。モデル内の等式拘束数は0です。持っている箱の変数は状態確認用であり、箱の位置を拘束しません。運搬中に箱の座標を直接書き換える処理もありません。

指は直動関節で開閉します。指の片側の中心位置は0.07〜0.16mの範囲、開く指令は0.15m、閉じる指令は0.075mです。片側の指の厚さは0.03mなので、開いたときの内側の間隔は約0.27m。対象の箱は一辺0.18m、質量0.15kgです。

閉じると箱が指を押し返すため、指令位置まで貫通せず、接触位置で押す力が生じます。左右の駆動力はそれぞれ±15Nに制限しています。通常の検証では片側約14.5Nの法線接触力を確認しています。

## 姿勢と制御
SCARAアームに手首の回転関節を追加し、箱の側面に指を合わせます。対象の箱の向きは現在も軸にそろえた固定向きです。

1. 指を開いて対象の上へ移動する。
2. 指を箱の側面の高さまで下げる。
3. 指を閉じ、両方の指が同じ箱に接触していることを確認する。
4. 持ち上げ、箱の高さが上がったことを確認する。
5. アームを折りたたみ、車輪で配送する。
6. 配送台の上へ移動して下げ、指を開いて置く。

把持の確認にはMuJoCoの接触力と箱の高さを利用します。実機の触覚センサやカメラだけでの把持判定ではありません。持ち上げ後と走行中に箱の中心が0.75mを下回ると、落下として停止します。配置の下降時はこの高さ判定を解除します。

## 長時間保持の滑り対策
最初の実装では静止保持はできても、長い運搬中に接触モデル上で少しずつ滑りました。摩擦を単に無限大にしたり固定拘束に戻したりせず、MuJoCoの楕円摩擦円錐、impratio=10、noslip_iterations=3を使用し、接触の数値的な滑りを抑制しました。

指パッドの滑り摩擦係数は1.5。これらはシミュレーション上の設定で、実物材料の測定値ではありません。NoSlipは摩擦計算の後処理であり、箱と指を接着する等式拘束ではありません。任意条件で滑らない保証もありません。

## 比較試験
同じ箱を対象に、既知座標で把持機構だけを検証しました。

| 条件 | 持ち上げ後の箱の中心高さ | 10秒後 | 結果 |
|---|---:|---:|---|
| 通常の指・摩擦 | 約0.918m | 約0.918m | 保持できる |
| 指を開いたまま | 約0.590m | 約0.590m | 台に残る |
| 指と箱の摩擦を低下 | 約0.590m | 約0.590m | 挟んでも持ち上がらない |

通常では開放後、箱が台上の高さ約0.590mへ戻ることも確認。全条件で固定拘束は0です。低摩擦条件は指と箱の滑り摩擦係数を0.0001に変更しています。

## 統合検証
- 認識器を固定した配置変更36ケース: 全て配送成功。箱の配置誤差は最大約4.84cm。
- 従来の6ケース: 全て通過。色の交換・対象なしの停止を含む。
- 車輪駆動の通常/低摩擦/モーター無効の3条件: 全て通過。
- 単体テスト10件: 全て通過。
- 別途、LLM・seed 0配置・車輪駆動・指把持の2件連続配送に成功。
- LLMデモでは箱の配置誤差約3.2cm、約3.5cm。障害物・作業台への接触検出は0。

固定した箱寸法・高さ・向き、既知の台と地図での結果です。未知物体、柔らかい物体、積み重ね、斜めの箱、多様な材質や重さは未検証です。自己位置と接触力はシミュレータから取得します。

## 実行
LLMサーバーを起動してから実行します。

```sh
./run.sh --demo --layout-seed 0 --video --video-speed 2 --output outputs/finger_llm_demo
./run.sh --gripper-evaluate
./run.sh --layout-evaluate
./run.sh --drive-evaluate
./run.sh --evaluate
./run.sh --test
```

LLMを使わず動作だけ確認する場合は --language naive_bayes を追加します。

動画は outputs/finger_llm_demo/demo.mp4（約2分19秒、2倍速を明記）。把持・配置中は右側の表示を指先のライブ拡大画像へ切り替えます。他の場面ではRGB認識画像を表示します。

把持時の静止画は同フォルダの grasp_1.png / grasp_2.png、持ち上げ後は lifted_1.png / lifted_2.png。接触力と把持段階の記録は results.json、3条件の比較は outputs/gripper_evaluation/summary.json に保存しています。

導入前はコミット cab69bd（codex/wheel-drive）。指把持のブランチは codex/finger-gripper。既存の説明資料PDFは吸着版のため、提出前に更新が必要です。
