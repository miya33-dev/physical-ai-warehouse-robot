# 荷物の配置変更

操作方法は現在も有効です。この文書の実測値は指把持導入前の記録であり、最新の検証結果は [指把持](指把持.md) を参照。

## 使い方
乱数の番号（seed）を指定すると、赤・青の箱のXY位置を台の上で変更します。同じ番号は同じ配置、違う番号は別の配置になります。

```sh
./run.sh --demo --layout-seed 0 --video --output outputs/layout_seed_0
./run.sh --demo --layout-seed 1 --video --output outputs/layout_seed_1
```

LLMサーバーを起動してから実行してください。LLMを使用しない場合は `--language naive_bayes` を明示します。配置オプションを指定しなければ従来の固定配置です。

自分で座標を指定する場合は `configs/layout_example.json` を編集します。

```json
{
  "red": [-2.05, 0.55],
  "blue": [-1.84, -0.45]
}
```

```sh
./run.sh --demo --layout-file configs/layout_example.json --video --output outputs/custom_layout
```

座標の単位はm。Xの変更は台の幅方向、Yの変更は台の長手方向です。--layout-seed と --layout-file は同時に指定できません。

## 現在の範囲
- X: -2.10〜-1.80 m。
- Y: -0.65〜0.65 m。
- 赤と青のY座標は0.28 m以上離す。
- 赤・青を各1個。箱の形・高さ・向きと、台・カメラ・障害物は固定。

この範囲は台からはみ出さず、既存のアームが届き、箱同士と吸着ヘッドが干渉しにくいよう限定しています。倉庫全体の好きな場所へ置ける機能ではありません。不正な配置は例外にして受け付けません。

## 位置を変えた後の処理
1. 従来の固定配置で認識器を学習する。
2. 認識器の学習を終えてから、シミュレーションの箱の初期位置だけを変更する。
3. 新しいRGB画像から指定色の位置を推定する。
4. 台の手前の固定X位置と、推定した箱のY位置を使って接近する。
5. 推定した箱のXY位置へアームを動かし、把持・配送する。

設定座標はシーンの初期化とログにだけ使用し、認識器へ正解位置を渡しません。録画は学習と配置設定の後に開始します。箱の移動は作業前の初期配置の変更です。作業中の箱の移動を追跡する機能は含みません。

## 確認結果（2026-11-02）
- 認識器を固定して、8 seed × 赤/青 × 出荷/保管の32ケースを検証。
- さらに台の端に置いた2配置 × 赤/青の4ケースを検証。
- 合計36/36ケースで、対象色の選択・配送・配置確認に成功。
- 認識位置の誤差: 平均約2.45 cm、最大約3.13 cm。
- 配置誤差: 最大約3.15 cm。中央障害物への接触は0。
- 検証の前後で認識器の学習パラメータが変化していないことを確認。
- 配置評価では言語部分を従来の分類器に固定し、画像認識と制御を評価。
- 別途、seed 0の配置でLLM版の2件連続配送にも成功。
- JSONによる任意配置のCLIも、2件連続配送で確認。

検証結果は outputs/layout_evaluation/summary.json。再実行:

```sh
./run.sh --layout-evaluate
```

初期配置を変更したLLMデモは outputs/random_layout_demo/demo.mp4（152.6秒）。動画冒頭とカメラ画像で、従来の赤・青の上下関係が逆になっていることを確認できます。

これらは固定カメラ・同じ台・既知の箱高さに限定した少数の検証です。未知背景・同色の複数箱・積み重ね・動く箱・一般的な3次元配置への対応は未実装です。
