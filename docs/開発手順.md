# 開発手順

## 1. 実行環境
この手順の初版は2026-11-02に実施済み。既存のPython 3.12とフォルダ内の .packages に導入したMuJoCo等を使用。再実行方法はREADME、結果は「実装と検証.md」を参照。

## 2. シーンとアーム単体
床・棚・箱・台車・アームを配置する。まず台車を止めた状態で、箱を持ち上げて置く。重力下で箱の位置と接触を確認する。

## 3. 移動単体
障害物を含む既知地図で経路を生成する。ロボットの幅と荷物の張り出しを考慮する。経路が作れても衝突していれば成功としない。

## 4. 認識
シミュレータのカメラ画像を保存し、認識器に入力する。認識器の入力に物体IDや正解ラベルを混ぜない。赤・青・対象なしのケースで確認する。

## 5. 自然言語理解
モデルの出力を target_color と destination に変換する。出力を検証し、任意のコード実行や未定義の動作に接続しない。言い換え・対象欠落・配送先不明を確認する。

## 6. 統合
IDLE → PARSE → PERCEIVE → APPROACH → PICK → TRANSPORT → PLACE → VERIFY → DONE の状態で接続する。失敗時はERRORで停止し、理由を記録する。

## 7. 評価
赤/青 × 出荷/保管の4通り、対象なし、配送先不明を確認する。試行数・成功数・所要時間・衝突・失敗理由を保存する。未実施の試験や未測定の成功率はレポートに記載しない。

## 8. 提出物
実行結果から動画とレポートを作る。公開用コードから個人情報・認証情報・講義配布資料を除く。公開とアップロード、最終提出は実際の成果物を確認してから行う。
